# Profile assets

- `header.png`: custom banner created for Haydar Majeed's profile.
- `badge-*.svg`: static badges generated with [Shields.io](https://shields.io/), using [Simple Icons](https://simpleicons.org/) where available. The Codex badge is text-only. Product names and logos identify tools, not endorsements or partnerships.

Badges are checked into this repository. Rendering the profile does not require visitor counters, analytics scripts, third-party stats services, or badge-generation requests. Badge labels do not represent measured proficiency or certification.

Design reference: [Beautify Your GitHub Profile Like a Pro](https://dev.to/ruppysuppy/beautify-your-github-profile-like-a-pro-5093). Adapted the badge and repository-presentation ideas; contribution activity is GitHub's own record.
